## 3. 地球与月球镜像五行宇宙学体系 (Earth vs Moon Five Elements)

在《始源晶石》的世界哲学中，地球与月球互为阴阳互补的共生天体：
- **地球法则：顺生正五行**（万物生长演化，金生水、水生木、木生火、火生土、土生金之循环基点，排布序列为：**金 → 木 → 水 → 火 → 地**）。
- **月球法则：逆转镜像五行**（虚空与反重力之镜，法则恰好完全反向颠倒，排布序列为：**地 → 火 → 水 → 木 → 金**）。

```
  ┌─────────────────────────────────────────────────────────────┐
  │                 【地球母界：正五行生生之环】                │
  │                                                             │
  │      [金 (Metal)] ───> [木 (Wood)] ───> [水 (Water)]        │
  │           ▲                                    │            │
  │           │                                    ▼            │
  │      [地/土 (Earth)] <──────────────────── [火 (Fire)]      │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
                            【镜像倒悬】
                                 │
  ┌──────────────────────────────▼──────────────────────────────┐
  │                 【月球双月界：逆五行倒悬之轨】              │
  │                                                             │
  │      [地/土 (Earth)] ───> [火 (Fire)] ───> [水 (Water)]     │
  │           ▲                                    │            │
  │           │                                    ▼            │
  │      [金 (Metal)] <─────────────────────── [木 (Wood)]      │
  └─────────────────────────────────────────────────────────────┘
```

### 3.1 地球母界五行阵眼（正五行：金·木·水·火·地）

对应地球表层文明与主线 30 章上半程的自然节点：

1. **【金之阵眼 (Metal)】— 第 13 ~ 15 章（织造工业城）**：
   - 地点：`factory_city`、工城大齿轮核心。
   - 概念：重工业与蒸汽核心，精金与机关齿轮所凝聚的物理绝对防御阵位。
2. **【木之阵眼 (Wood)】— 第 5 ~ 6 章（世界树与仙林西径）**：
   - 地点：`maze_wood`、`yggdrasil` 枯枝与古林。
   - 概念：大自然生生不息的原始生机，林海脉动与生命回流阵位。
3. **【水之阵眼 (Water)】— 第 8 ~ 9 章（托尔纳水闸与人鱼湾）**：
   - 地点：`mermaid_bay`、托南水闸蒸汽坞。
   - 概念：洋流潮汐与深海寒冰的流动智慧，全屏水幕与润物之位。
4. **【火之阵眼 (Fire)】— 第 11 ~ 12 章（烬堡废墟与火矶城）**：
   - 地点：`ash_keep` 熔岩回廊。
   - 概念：烈火焚尽一切的狂暴毁灭之力，赤色业火爆发之位。
5. **【地之阵眼 (Earth / 土)】— 第 19 ~ 20 章（古王陵墓与古王国）**：
   - 地点：`old_kingdom`、先王古陵磐石墓穴。
   - 概念：承载一切的厚重地脉与坚不可摧的大地之脊。

### 3.2 月球镜像界五行阵眼（逆五行：地·火·水·木·金）

对应青之月/红之月及主线 30 章下半程的登月与虚空前夜：

1. **【地之镜像 (Earth / 土)】— 第 27 章（月面静海）**：
   - 地点：`lunar_mare` 月岩风暴洋。
   - 概念：月球引力失衡形成的重力倒悬断崖，逆向五行的起始锚点。

   - 地点：`vermilion_crevasse` 反物质耀斑源。
   - 概念：冰冷虚空中的反常虚火，灼烧精神与以太的暗物质火核。

   - 地点：`lunar_frozen_sea` 固态水冰洞穴。

4. **【木之镜像 (Wood)】— 第 29 章（苍月古树逆生根）**：
   - 地点：`pale_moon_roots` 虚空生机胚芽。

   - 地点：`lunar_palace` 皇帝前殿。
   - 概念：高维神族遗留的超合金白金外壳，封锁非之世界的终极金属大门。

## 6. 五行相生相克伤害乘区与九大行星战场修正表

### 6.1 地球正五行 vs 月球逆五行伤害乘区矩阵

在地球母界（Ch.01~22）与月球双月界（Ch.27~29）战斗时，五行属性遵循各自的生克乘区：
- **相克（Counter）**：造成 **1.50x** 弱点伤害（标记 `WEAK`）。
- **相生（Generate / 同源滋养）**：若攻击属性生助目标属性，伤害衰减为 **0.75x**；在第 30 章「五行圣所（`void_five_phases`）」5 体同台战中，相生属性攻击会为对应灵神恢复 **25% 伤害值** 的 HP。

| 攻击属性 \ 目标属性 | 金 (Metal) | 木 (Wood) | 水 (Water) | 火 (Fire) | 土/地 (Earth) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **金 (Metal)** | 1.00x | **1.50x (金克木)** | 0.75x (金生水) | 1.00x | 1.00x |
| **木 (Wood)** | 1.00x | 1.00x | 1.00x | 0.75x (木生火) | **1.50x (木克土)** |
| **水 (Water)** | 1.00x | 0.75x (水生木) | 1.00x | **1.50x (水克火)** | 1.00x |
| **火 (Fire)** | **1.50x (火克金)** | 1.00x | 1.00x | 1.00x | 0.75x (火生土) |
| **土/地 (Earth)** | 0.75x (土生金) | 1.00x | **1.50x (土克水)** | 1.00x | 1.00x |

> **月球逆五行反转规则**：进入月球逆五行法阵（`lunar_reversal_matrix`）后，生克方向全面逆置——被克方反噬克制方（即 **木反克金、土反克木、水反克土、火反克水、金反克火** 造成 1.50x 伤害），并在战场 HUD 顶部常驻显示 `【逆五行倒悬】` 紫色徽标。
