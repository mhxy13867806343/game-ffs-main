### 从“地球出生”开始，而不是从恐龙开始

地球约形成于 **45 亿年前**，但地球刚形成时并没有已知的大型动物。生命史的早期与现代的巨兽想象相距甚远；本文的具名动物表从早期大型／多细胞动物记录进入，而不是虚构一批“地球诞生时的魔兽”。[EARTH](#source-earth) [PALEO](#source-paleo)

| 时间段（约数） | 在这份图鉴中的位置 |
|---|---|
| 地球形成至早期生命时代 | 背景阶段，不列没有科学证据的巨型怪兽。 |
| 埃迪卡拉纪与寒武纪 | 早期动物、奇虾、怪诞虫等。 |
| 奥陶纪至二叠纪 | 古海洋生物、大型节肢动物、早期陆地合弓类。 |
| 三叠纪、侏罗纪、白垩纪 | 恐龙，以及同时期但不属于恐龙的海生爬行动物、翼龙等。 |
| 约6600万年前之后 | 非鸟类恐龙灭绝后的巨蛇、巨鲨、古鲸与大型哺乳动物。 |
| 今天 | 另见第2章的现生动物。 |

时间框架参见自然历史博物馆与史密森学会资料入口；表中某属的年代不表示它贯穿整个地质时期。[DINO](#source-dino) [PALEO](#source-paleo)

**本章有意不填写“史上最强”“绝对第一”“确定体长几十米”等未经充分支持的数值。** 化石复原、体型估计、生活方式可能修订；例如巨齿鲨的尺寸估计并非一个永远不变的精确值。[MEG](#source-meg)

## 03｜中国上古神话：蚩尤、刑天与创世诸神

### 蚩尤，当然应当在这一类里面

**蚩尤**属于中国上古传说的重要人物：传统叙事把他与战争、兵器以及黄帝的战争相联系。《山海经·大荒北经》还把蚩尤、应龙、女魃等放在相关叙述中。**这说明古籍中存在这些故事，不是已经考古证实所有法术或异形身体。** 不同群体对蚩尤也可能有祖先、神灵或战争对手等不同理解，不能只用“坏怪物”概括。[SHJN](#source-shjn) [CHI](#source-chi)

### 冥界 ≠ 地狱 ≠ 撒旦的统一王国

**希腊冥界、北欧赫尔的领域、中国十殿、基督教地狱观念，以及伊斯兰教相关传统，并不是一套共同的官职系统。** 神话中管理死亡或亡者的神祇，不一定是邪恶者；《古兰经》18:50对伊布利斯的归属也不能改写成“所有精灵都是恶魔”。[GRHELL](#source-grhell) [EDDA](#source-edda) [TEN2](#source-ten2) [QURAN](#source-quran)

本章同时收录宗教经典形象、民间传说、文学魔鬼与历史恶魔学名称，**但在来源栏分别标明**。《Goetia》的称号、排序属于特定历史文本，不是今天所有宗教共同承认的地狱组织架构。[DEMON](#source-demon) [GOETIA](#source-goetia)

### 先把四种“月球上面的”分开

| 情况 | 这里如何收录 |

### 你特别提到的《最终幻想4：月之归还》

这是《FF4》的续作，官方发行介绍把故事放在原作事件 **17年之后**，并介绍了另一个月亮出现及后续危机。[TAYOFF](#source-tayoff)

**《FF4》的泽姆斯／泽罗姆斯，与《月之归还》的造物主不是同一个最终Boss。** 续作的 **真月（True Moon）** 是造物主的飞船式载体，与他记录、筛选生命的水晶实验相联系；“神秘少女”也不是只有一个人的身份。详细角色按下表分别列出。[FF4CHAR](#source-ff4char) [TAY](#source-tay)

| FF4 原版及重制版 | 月球首领与其他大陆上的Boss分开；不同移植版的隐藏内容不能一概相同。 |

## 附录B：最容易弄混的地方

| 容易混淆 | 应当分开 |
|---|---|
| 蚩尤 = 一个已考古证实的多臂怪物 | 古籍传说、祖先／神灵观念、后世游戏造型三层不同。[CHI](#source-chi) |
| 秦始皇 = 不死尸皇 | 历史皇帝与作品虚构身份不同。[SHIJI](#source-shiji) |
| 沧龙、翼龙、异齿龙都是恐龙 | 它们分别属于不同生物支系；带“龙”字不等于恐龙。[PALEO](#source-paleo) [DIMET](#source-dimet) |
| 巨齿鲨还在深海 | 没有可靠证据支持其今天仍存活。[MEG](#source-meg) |
| 冥界之王都是邪恶魔王 | 哈迪斯、阎罗等涉及不同传统中的亡者管理与审判观念。[GRHELL](#source-grhell) [TEN2](#source-ten2) |
| 路西法、撒旦、哈迪斯属于同一地狱编制 | 分属不同文本解释、神话和文学传统。[DEMON](#source-demon) [GRHELL](#source-grhell) |
| 所有Maenad都是同一个人或永远邪恶 | 续作呈现不止一个个体，并有不同角色走向。[FF4CHAR](#source-ff4char) |
| FF4月球 = 月之归还真月 = 现实月球 | 三者的语境、地点性质不同。[FF4CHAR](#source-ff4char) [MOON](#source-moon) |
| 月球主题的Boss一定在现实月球出生 | 必须看作品明示；名称与出生地不是一回事。 |
| 利维坦、提亚马特、莉莉丝跨作品都是一个角色 | 神话原型、后世改编、独立世界观应分别编目。 |
| 神兽、幻兽、神祇都应列为反派 | 图鉴收录的是强大或有代表性的存在，不是敌人黑名单。 |
| 多个作品里的“最终Boss”可以直接排出客观第一 | 世界规则与叙事标准不同；没有本文能够据此证明的统一数值尺度。 |

## 附录C：继续扩充时采用的记录格式

这是资料组织建议，不是声称所有作品都有这些系统。

```text
编号：Bxxxx
名称：中文名 + 原文／英文名
性质：真实动物 / 历史人物 / 神话宗教 / 文学 / 游戏 / 动漫 / 影视
来源：具体作品、文化传统或地质时代
粒度：个体 / 物种或种族 / 群体组合 / 角色形态
身份：普通生物 / 强敌 / Boss / 最终Boss / 神祇 / 友方 / 守护者
地点：现实地点或作品内地点；不猜测出生地
特征：外观、核心能力或剧情功能，注明作品版本
证据：原作、古籍、科学机构、博物馆、官方图鉴或可靠资料
差异：译名、版本、时间线、同名不同实体
```

本版以“名称、身份、来源、识别特征”为主。**没有填写所有条目的掉落、技能数值、血量、地图坐标、剧情全文或每个物种的精确尺寸。** 用于创作时，原作角色与名称的权利归属也需要另外考虑；本图鉴不是对商业使用的授权。
